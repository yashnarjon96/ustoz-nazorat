## Ishga tushirish
1. ZIP faylni chiqarib oling.
2. VS Code’da shu papkani oching.
3. `index.html` faylini brauzerda oching yoki VS Code Live Server orqali ishga tushiring.
4. `npm install` shart emas.

## Demo imkoniyatlari
- Admin: o‘qituvchi va o‘quvchi qo‘shish/o‘chirish, bo‘limlarni ochish.
- O‘qituvchi: o‘quvchi, davomat, dars va to‘lov ma’lumotlarini boshqarish.
- Ota-ona: farzand profilini, davomat, dars va to‘lov holatini ko‘rish, to‘lov xabari yuborish.
- Ma’lumotlar shu brauzerning localStorage xotirasida saqlanadi.

## Muhim cheklov
Bu to‘liq mahalliy demo. Boshqa kompyuter/telefon bilan umumiy ma’lumot almashmaydi va haqiqiy xavfsiz login serveri emas. Internetda barcha foydalanuvchilar bir xil ma’lumot ko‘rishi uchun backend/Firebase va ota-ona hisobini himoyalangan tarzda bog‘lash zarur. Haqiqiy o‘quvchilar ma’lumotini demo versiyaga kiritmang.


## Ota-onalar uchun yangilanish
- Ota-ona parolsiz kirishi mumkin.
- Ota-ona “O‘quvchilar” bo‘limida farzandining ismini bosib profilini ko‘radi.
- “To‘lov qildim” tugmasi o‘qituvchiga tasdiqlash so‘rovini yuboradi.
- O‘qituvchi “To‘lovlar” bo‘limida so‘rovni tasdiqlasa, to‘lov holati “To‘lov qilindi” bo‘ladi.
